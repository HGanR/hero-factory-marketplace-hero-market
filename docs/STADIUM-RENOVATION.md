# Troothhertz Stadium renovation

The generated empty-venue image is the visual reference, not a texture substituted for actual geometry. The existing stadium GLB is cloned; its rear stage, floating audience markers, obstructing scoreboard and seating slabs are retired in that clone. The source file stays unchanged.

The replacement is a deterministic Three.js venue: inward-facing rounded seat cushions and backs on stepped terraces, four seat-free radial stairs with illuminated treads and brass rails, a central circular microphone stage, 12 guest seats in a controlled inner ring, acoustic wall fins, raised main and secondary media screens, an overhead lighting truss with four actual host spotlights, teal accent lighting, and glass double doors on all four exterior hall appendages. Clicking an exterior door uses the existing guarded stadium-entry flow. Exterior world labels disappear during an interior visit and return on exit. Decorative procedural grass spikes and procedural rocks are removed; saved trees and placed library assets remain editable.

Placement, rotation, scale, undo, saved layout, mobile/desktop walking, admission policy, event scheduling, main-screen image/MP4, billboard text, and ticker text/letter sizing retain their existing interfaces. Saved media and custom ticker content retain precedence; an unused screen defaults to TROOTHHERTZ STADIUM. No layout/schema migration is required. Preview saves remain isolated from the live layout.

The stair/floor collision model covers all four radial stairs and a narrower unobstructed upper concourse. Ordinary visitors cannot enter the stage/guest ring or cut through seating. Guest invitation/role admission into the inner ring is not introduced by this visual renovation; that remains separate from the existing paid-event entry checks. Seat geometry count is not a concurrency or avatar-performance promise. Existing paid-event activation requirements remain unchanged.

Validation includes seat footprint/aisle intersection checks, inward orientation, actual GLB cloning, owned-resource disposal, four entry doors, elevated screen coordinates, scaled/rotated first-person descent and restricted zones, plus real WebGL screenshots and regression checks for image/MP4/ticker/event persistence and mobile/desktop walking. Final imagery must be reviewed from the entry and floor; this is a real-time approximation of the reference, not a claim of pixel-identical photoreal rendering.
